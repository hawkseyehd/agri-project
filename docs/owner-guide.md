# Owner Guide

Owners and admins manage the full farm operation.

## Main Tasks

- Sign in at `/login`.
- Review dashboard summaries.
- Create and review farms.
- Assign managers to farms.
- Create land blocks.
- Create crop seasons.
- Review daily reports.
- Review labor, expenses, inventory, harvests, sales, and reports.
- Manage settings, categories, units, profile, and notification preferences.
