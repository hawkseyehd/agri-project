# Owner User Guide

Owners and admins manage the full farm operation from the web app.

## Daily Workflow

1. Sign in at `/login`.
2. Review dashboard summaries for farm performance, inventory, labor, expenses, harvests, and sales.
3. Create farms and land blocks as operational areas are added.
4. Create crop seasons for each active block.
5. Review manager-submitted daily reports.
6. Track harvests, sales, receivables, and profit/loss reports.

## Settings

Use `/settings` to:

- Create manager accounts.
- Assign managers to one or more farms.
- Review default operating categories and units.
- Update your profile and password.

Only owners/admins can access user management. Managers see profile and notification settings only.
