# Manager Guide

Managers record operational activity for assigned farms.

## Main Tasks

- Sign in at `/login`.
- Open assigned farms only.
- Review assigned land blocks and crop seasons.
- Create or edit daily reports for assigned crop seasons.
- Record labor, expenses, inventory usage, irrigation, inputs, issues, photos, harvests, and sales where permitted.

## Access Rules

Managers must not see unrelated farms. All manager data access should be filtered by assigned farm IDs on the server.

## MVP Notes

Manager account creation and assignment belong to Settings. Full manager workflow QA is still required before first-farm testing.
