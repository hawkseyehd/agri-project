# Core Workflow

1. Owner creates account and logs in.
2. Owner creates farms and assigns managers.
3. Owner or manager creates land blocks.
4. Owner or manager creates crop seasons for land blocks.
5. Manager submits an end-of-day report.
6. System updates activities, labor, expenses, inventory, irrigation, and input usage.
7. Manager records harvest.
8. Manager records sales.
9. Owner reviews dashboard and reports.
10. System calculates crop, block, and farm-level profit/loss.
